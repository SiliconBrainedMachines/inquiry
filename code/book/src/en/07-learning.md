# Learning — Can You Improve Without Living?

Meta-learning, self-improving AI, DARWIN. What is genuine learning? This chapter convokes Dewey, Piaget, Vygotsky, and the Buddhist tradition to examine what it means to learn, why experience is irreplaceable, and how iterative refinement is structured pragmatism.

The emergent tool: **iterative refinement as discipline.** The cycle of analyze, plan, execute, and learn — rooted in Dewey's pragmatism and constructivist epistemology.
