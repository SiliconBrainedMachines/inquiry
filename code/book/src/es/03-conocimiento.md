# Conocimiento — ¿Conocer es recordar o computar?

RAG, MemGPT, bases de datos vectoriales — estamos construyendo memoria para las máquinas. ¿Pero qué es "saber" algo? Este capítulo convoca a Platón, Locke, Hume, Kant y Popper para examinar qué es el conocimiento, de dónde viene, y por qué pedirle a una máquina que refute en vez de confirmar es la tradición más fuerte de la epistemología.

La herramienta emergente: **pensamiento falsificacionista.** Contrarrestar el sesgo de confirmación del LLM invocando la asimetría de Popper entre verificación y falsificación.
