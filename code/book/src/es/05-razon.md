# Razón — Deducción, inducción, abducción y las máquinas

Los LLMs no deducen ni inducen — abducen. ¿Qué significa eso para la fiabilidad? Este capítulo convoca a Aristóteles, Peirce, Popper y Kahneman para examinar los tres modos de inferencia, por qué el modo nativo de la máquina es la abducción, y qué significa eso para cómo debemos dirigirla.

Este es el **capítulo pivote** donde el método científico se establece como el benchmark contra el cual se miden todas las demás herramientas de pensamiento del libro.

La herramienta emergente: **razonamiento estructurado.** Cadena de pensamiento como mayéutica computacional. Pensamiento taxonómico. Estructura silogística.
