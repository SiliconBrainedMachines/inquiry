# Lenguaje — ¿Puede una máquina significar?

La ingeniería de prompts asume que el lenguaje puede capturar la intención con precisión. ¿Pero puede? Este capítulo convoca a Platón, Zhuangzi, Wittgenstein, Saussure y Derrida para examinar qué es el significado, cómo funciona, y por qué la elección de palabras en los prompts importa — no como un consejo, sino como consecuencia de entender cómo opera el lenguaje mismo.

La herramienta emergente: **precisión semántica.** No "sé específico" — sino entender *por qué* la especificidad funciona, a través del lente de 2,500 años de filosofía del lenguaje.
